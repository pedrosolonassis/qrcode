### Objetivo Geral:
Desenvolver uma aplicação web que demonstre compreensão dos principais conceitos HTML, CSS e JavaScript estudados na disciplina, visando:
-> Facilitar a integração da satisfação do cliente com a avaliação google do estabelecimento;
-> Demonstrar, por meio de dados com gráfico, o número de toques por dia no QRCode e no NFC;
-> Estilizar o QRCode da placa/adesivo;
-> Sumarizar os principais dados na página inicial, como avaliação atual, médias, toques e scan.
